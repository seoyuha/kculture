# K-Culture 마스터 (6학년 영어 11단원 스플렌더 게임)

학생들이 영어 문제를 맞혀 전통문화 자원(토큰)을 모으고, 그 자원으로 전통문화 카드를 사서 점수를 모으는 스플렌더 방식 게임입니다.

- 학생 화면: `https://내주소/`  (QR·`?code=1234` 주소로 들어오면 방 코드가 자동 입력)
- 교사 화면: `https://내주소/teacher.html`

## 통합 그래픽 · 확정 규칙 (2026-10-31 업데이트)
- 그래픽 패키지(스플렌더.zip)의 학생 메인 보드·팝업·버튼·결과 그림·교사 화면 시안대로 전체를 바꿨어요.
- 카드는 확정 규칙표(card_rules_30_types_60_copies.csv) 그대로: 30종 × 2장 = 60장, 1·2·3단계 각 10종, 점수 0~4점.
- 학생 화면: 카드 시장(단계별 4장) · 보너스 카드 5종 · 공동 자원 · 친구 4명 공개 정보(토큰·영구 할인·구매/예약 카드) · 내 칸 · 버튼 4개.
- 교사 화면: **실시간 모니터(6방 미니 화면)** · 선택한 방 · 실시간 진행 상황 · 교사 메시지 보내기 · 시간 연장(+30초/1분/2분/5분) · 방 종료 확인 · 게임 종료 결과(최종 점수/영어 문제 분석/카드 획득 현황).

## 1. Render에 올리기 (다른 게임과 같은 방법)
1. 이 폴더를 GitHub 저장소에 올립니다. (`node_modules`, `data`는 올리지 않아도 됩니다)
2. Render → New → Web Service → 저장소 선택
3. Build Command: `npm install` / Start Command: `npm start`
4. 배포가 끝나면 나온 주소 뒤에 `/teacher.html`을 붙여 교사 화면을 엽니다.

> 무료 Render는 한동안 안 쓰면 잠들어서 첫 접속이 30초~1분 걸려요. 수업 전에 교사 화면을 한 번 열어 깨워 두세요.
> 문제를 고쳐 둔 적이 있다면, 이번 버전은 그림 퀴즈 카드로 문제가 새로 바뀌어서 처음 한 번은 기본 문제로 시작해요.
> 서버가 다시 시작되면 진행 중인 수업·결과는 사라집니다. 결과는 게임이 끝날 때마다 **결과 보기 → 엑셀(CSV) 저장**으로 받아 두세요.

내 컴퓨터에서 시험해 보기: `npm install` → `npm start` → http://localhost:3000

## 2. 수업 진행 순서
1. 교사 화면에서 **새 수업 만들기** → 방 코드 4자리와 QR이 나옵니다.
2. 학생: 시작 화면 **Game Start** → 이름·방 코드 → 캐릭터 선택 → 대기실
3. 팀 만들기 (두 가지 다 됩니다)
   - **교사 배정**: 학생 배정 → 팀 인원 수 선택 → **자동 배정하기** (인원이 고르게 나뉨). 드롭다운으로 학생을 다른 팀으로 옮길 수 있어요.
   - **학생 방 만들기**: 대기실에서 **방 만들기** → 친구들이 **들어가기**. 방장(👑)이 **게임 시작**을 누를 수 있어요. (게임 설정에서 끌 수 있음)
4. **게임 시작하기** → 대기 중인 모든 팀이 동시에 시작합니다.
5. **실시간 모니터링**: 팀 카드를 누르면 오른쪽에 그 팀의 시장·학생별 자원·지금 푸는 문제와 정답·진행 로그가 보여요. 일시 정지·시간 연장(+5분)·게임 종료·차례 넘기기 가능.
6. 게임이 끝나면 **같은 팀으로 새 게임** 또는 **팀 풀고 대기실로**. 결과는 판마다 쌓이고 학생별 누적 점수·정답률을 볼 수 있어요.

## 3. 게임 규칙 (10분 수업용 빠른 진행 · 기본값)
- **자원 가져오기 → 영어 문제**: 서로 다른 자원 3개 또는 같은 자원 2개(창고에 4개 이상일 때)를 고르면 영어 문제가 나와요. 맞히면 고른 자원을 **2배**로 받고, 틀리면 받지 못해요.
- **카드 예약하기**: 시장 카드 1장을 찜하고 황금 1개를 받아요. 예약은 3장까지.
- **카드 구매하기**: 한 차례에 1장. 자원 가져오기나 예약을 한 뒤에도 같은 차례에 살 수 있어요. 카드 비용에서 영구 할인을 뺀 만큼 내고, 모자라면 황금으로 대신 내요.
- 자원은 10개까지. 넘게 가져올 때는 돌려줄 자원을 골라요(정답일 때만 바꿔요).
- 공동 자원: 5종 × 7개 + 황금 5개 (2명 방 4개, 3명 방 5개).
- 보너스 카드 5종(각 +3점): 정해진 세 종류의 카드를 3장씩 모으면 차례 끝에 받아요.
- **목표 5점**에 누가 닿으면 그 바퀴까지만 하고 끝. **제한 시간 10분**이 되면 바로 끝나고 그때 점수로 순위를 정해요.
- 동점이면 카드가 적은 학생 → 정답이 많은 학생 순.
- 교사 설정에서 빠른 진행을 끄면 패키지 원래 규칙(한 차례 한 행동, 자원 1배)으로 돌아가요. 목표 점수 3~15점, 제한 시간 5~30분도 바꿀 수 있어요.
- 참고(봇 시뮬레이션): 원래 규칙으로는 10점까지 약 25바퀴, 빠른 진행에서도 5점까지 약 7~9바퀴가 걸려요. 5명 방은 10분에 4~5바퀴 정도라 대부분 시간 종료로 끝나요.

## 4. 문제 관리
- 기본 문제 110개 (자원 종류별 22개: 그림 퀴즈 카드 6 · 설명 읽고 이름 6 · 11단원 표현/대화 10)
  - 그림 퀴즈 카드 30장은 선생님이 만든 QUIZ 카드의 사진·보기·정답 그대로예요.
- 대기실에서는 팀을 기다리는 동안 그림 퀴즈 연습(점수 없음)을 할 수 있어요.
- 교사 화면 **문제 관리**에서 추가·수정·끄기·삭제할 수 있고, 서버의 `data/questions.json`에 저장돼요.
- **엑셀 양식 다운로드** → 엑셀에서 문제를 쓴 뒤 **엑셀 업로드**(xlsx·xls·csv)로 한꺼번에 더할 수 있어요.
  (자원종류: food/clothing/play/craft/heritage 또는 음식/의복/놀이/공예/문화유산, 정답번호 1~4)
- Render 무료 서버는 다시 시작하면 `data` 폴더가 지워져요. 문제를 많이 고쳤다면 CSV로 내보내 보관하세요.
